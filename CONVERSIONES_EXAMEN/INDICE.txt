 COMO USARLO EN EL EXAMEN
---------------------------------------------------------------------
 1. Lee el enunciado: ¿de QUE formato a QUE formato? -> busca el paquete.
 2. Copia el paquete entero (o sus .java) a tu proyecto del examen.
 3. Cambia SOLO lo marcado con "CAMBIAR":
      - Pokemon.java: atributos del enunciado (+ getters, constructor, toString)
      - nombres de los ficheros (FICHERO_...)
      - TXT: SEPARADOR y la posicion de cada campo
      - XML: RAIZ_XML y las ETIQUETA_...
      - JSON: @SerializedName de Pokedex y los atributos de Pokemon
      - BBDD: URL / USUARIO / PASSWORD y el SQL
 4. Ejecuta: mostrarLista() te dice si la LECTURA ha ido bien.

 LAS 10 PIEZAS (son las mismas en todos los paquetes)
   leerTXT   / escribirTXT   -> BufferedReader / BufferedWriter
   leerDAT   / escribirDAT   -> ObjectInputStream / ObjectOutputStream (lista entera)
   leerXML   / escribirXML   -> getElementsByTagName / createElement + grabarXML
   leerJSON  / escribirJSON  -> gson.fromJson(Pokedex) / gson.toJson(Pokedex)
   leerBBDD  / escribirBBDD  -> SELECT + executeQuery / INSERT + executeUpdate

 LIBRERIAS (ya en lib/ y en el Build Path del proyecto)
   gson-2.14.0.jar  y  mysql-connector-j-26.7.0.jar
   Si copias a otro proyecto: Build Path -> Add JARs. Sin module-info.java.

 BBDD: pokemondb cargada en Docker. Tabla pokemon(numero_pokedex, nombre, peso, altura).
   Los INSERT de ejemplo (152, 155, 158) no existen en pokemondb; Pikachu (25) si -> se salta.
   Para repetir: DELETE FROM pokemon WHERE numero_pokedex > 151;
